잔고·현금·계좌 평가액을 휴대폰에서 직접 조회합니다.

Android APK 다운로드

Android 8.0 이상 · 개발용 서명 APK
기존 0.5.2와 같은 서명으로 업데이트할 수 있습니다.

한 번 연결하면, 잔고 입력 없이.

  1. 휴대폰에서 APK를 내려받아 설치합니다.
  2. 내 자산 → 메리츠 계좌를 엽니다.
  3. 본인이 발급받은 메리츠 App Key·App Secret을 입력합니다.
  4. 암호화 저장하고 메리츠 연결을 누릅니다.

키·계좌 기록은 기기에 암호화 저장합니다. 메리츠 공식 서버에 직접 인증하며 GitHub로 전송하지 않습니다. PC 서버·Tiingo·Firebase 없이 계좌를 조회할 수 있습니다. 이 연결 기능은 주문을 보내지 않습니다.

계좌 조회와 모델 결과

메리츠 계좌는 직접 조회합니다. 공개 모델 결과는 2026-10-20 과거 미리보기이며 최신 신호 자동 계산은 검증 중입니다. 계좌 순투입금·전체 입출금 분류·TQQQ 실제 비교와 푸시 알림은 아직 준비 중입니다.

총자산은 메리츠가 제공한 평가액입니다. 보유 종목 평가수익률은 실현손익·배당을 포함한 계좌 누적수익률과 다릅니다. 기기 절전·통신·API 권한에 따라 조회가 지연될 수 있습니다. 실제 휴대폰 계좌 대조가 필요합니다.

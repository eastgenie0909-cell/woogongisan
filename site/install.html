홈 화면에 맞는 세 가지 위젯

요약 3×2 · 그래프 5×2 · 상세 5×3. 홈 화면을 길게 눌러 위젯 → 우공이산에서 선택하세요. 공간이 작아지거나 글꼴이 커지면 요약형으로 자동 전환합니다. 앱과 위젯은 시스템 화면 모드를 따릅니다.

기존 앱 위에 업데이트하세요. 새 스타일은 기존 위젯을 지우고 원하는 종류로 다시 추가하면 됩니다. 실제 칸 수와 표시 크기는 런처에 따라 다릅니다.

같은 기간, 세 개의 선.

민트: 우공이산 모델 · 파랑: TQQQ · 금색: 버크셔 B(BRK.B). 시작점은 모두 0%이며 USD·세전 수익률입니다. 앱에서 1개월·3개월·1년·전체를 선택하고, 위젯의 기간 버튼으로 개별 기간을 바꿀 수도 있습니다.

모델 시뮬레이션: 원본 가격기준·다음 종가·편도0.1% 비용 / 비교종목: 배당·분할 반영 수정종가, 매수 후 보유. 개인 계좌 수익률이 아닙니다.

위젯 컬렉션 미리보기 →

한 번 연결하면, 잔고 입력 없이.

  1. 휴대폰에서 APK를 내려받아 설치합니다.
  2. 내 자산 → 메리츠 계좌를 엽니다.
  3. 본인이 발급받은 메리츠 App Key·App Secret을 입력합니다.
  4. 암호화 저장하고 메리츠 연결을 누릅니다.

키·계좌 기록은 기기에 암호화 저장합니다. 메리츠 공식 서버에 직접 인증하며 GitHub로 전송하지 않습니다. PC 서버·Tiingo·Firebase 없이 계좌를 조회할 수 있습니다. 이 연결 기능은 주문을 보내지 않습니다.

계좌 조회와 모델 결과

메리츠 계좌는 직접 조회합니다. 모델 결과는 Yahoo Finance·Bitstamp의 완료 종가로 자동 계산합니다. 앱의 ‘오늘 → 최신 결과 확인’을 누르면 최신 완료 거래일의 목표·그래프를 받아옵니다. 메리츠 계좌 연결과 모델 시세 조회는 별개이며 추가 키는 필요하지 않습니다. 개인 계좌 순투입금·전체 입출금 분류·개인 계좌와 TQQQ의 비교는 별도 미완료입니다. 장 마감 알림은 기기 자체 알림을 사용합니다.

총자산은 메리츠가 제공한 평가액입니다. 보유 종목 평가수익률은 실현손익·배당을 포함한 계좌 누적수익률과 다릅니다. 기기 절전·통신·API 권한에 따라 조회가 지연될 수 있습니다. 실제 휴대폰 계좌 대조가 필요합니다.

장 마감 알림

0.6.1부터 Firebase 없이도 새 장 마감 결과를 받으면 휴대폰에서 알립니다. 설치 후 앱의 설정 → 장 마감 알림 → 알림 테스트를 눌러 확인하세요. 알림이 차단돼 있으면 ‘휴대폰 알림 설정 열기’에서 허용합니다.

백그라운드에서 약 30분마다 조회하며 절전·통신·서버 게시 지연에 따라 늦어질 수 있습니다. 정각 알림을 보장하지 않습니다. 같은 모델·거래일은 한 번만 알리고, 예시·오류·만료된 결과는 알리지 않습니다.

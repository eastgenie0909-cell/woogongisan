# 우공이산 앱 · V1.3-D

Android 앱과 홈 화면 위젯, 웹 대시보드, 장 마감 계산 파이프라인입니다. 앱 버전은 0.6.2이며 기본 투자 모델은 **우공 V1.3-D = D25**입니다.

기존 3661 코어 → Cross5·GLD21 → QQQ SMA200 약세 시 방어 몫 25% 달러 현금 순서로 적용합니다. 강제 BRK.B 상태에도 D25를 적용하고, 재조정 문턱은 12.5%p입니다. 목표 비중·적용 이유·상대강도/방어/낙폭 차트·모델별 과거 성과·개인 보유량 비교를 표시합니다.

내장 오프라인 자료는 **2026-10-20 과거 미리보기**이며, 온라인 모델 결과는 [GitHub Pages](https://eastgenie0909-cell.github.io/woogongisan/)에서 최신 완료 거래일로 갱신합니다. 모델은 원본 혼합 가격기준을 보존한 Yahoo Finance·Bitstamp 데이터로 자동 계산하고, 개인 계좌는 Android에서 메리츠에 직접 조회합니다. Tiingo 키가 필요하지 않습니다. 0.6.1부터 새 종가 결과는 휴대폰 자체 알림으로 알려주며 Firebase 설정이 필요하지 않습니다. 연구의 본운용 미승인 상태와 주문 잠금을 유지합니다. 개발용 APK의 빌드 성공과 실제 휴대폰의 푸시·위젯 동작 검증은 별개입니다.

## 첫 화면과 5×2 위젯

우공이산 모델·TQQQ·버크셔 B(BRK.B)의 동일 기간 수익률을 세 선으로 비교합니다. 기본은 최근 1개월이며 앱에서 3개월·1년·전체를 선택하면 위젯에도 같은 기간을 적용합니다. 모두 시작 0%, USD·세전입니다. 개인 계좌 수익률은 이 그래프에 사용하지 않습니다.

모델 선은 기존 최신 확장 시뮬레이션(원본 혼합 가격기준·다음 종가·편도0.1%·현금금리0)입니다. TQQQ·BRK.B는 배당·분할 반영 수정종가의 매수보유 수익률입니다. 실계좌 성과와 구분합니다. 범위 내 결측은 보간하거나 날짜를 삭제하지 않으며, 비교 자료 오류 시 ‘비교 자료 갱신 대기’로 표시합니다. 최신 목표 신호 조회는 별도로 유지합니다.

## 내 자산

Android 0.6.0은 **내 자산 → 메리츠 계좌**에서 App Key·App Secret을 기기에 암호화 저장하고 공식 메리츠 API를 직접 조회합니다. 잔고·현금·계좌 평가액을 수동 입력할 필요가 없습니다. 기존 수동 기록과 개인 서버 운용 센터는 별도 탭입니다. 직접 조회는 계좌 조회만 지원하며 주문은 보내지 않습니다. [내 자산 상세 안내](ASSETS_GUIDE.md)를 확인하세요. 실기기에서 실제 계좌를 불러오는 검증은 새 APK 설치 후 필요합니다. 모델 자동 계산의 시세 검증과 계좌 자산 조회는 별개입니다.

## 운용 센터

관찰·반자동·자동 모드, 메리츠 잔고·주문가능금액 조회, 주문안 확인, 가상 기록, 주문 접수·체결 대조를 추가했습니다. 기본값은 관찰이며 실제 인증키·실주문은 연결하지 않았습니다. [운용 센터 설정 안내](TRADING_GUIDE.md)를 확인하세요. 웹은 운용 센터 링크, Android는 내 자산 → 운용 센터에서 엽니다.

## 모델을 바꾸는 방법

모델은 투자 전략을 뜻합니다. Android 화면 코드에 모델 번호나 재조정 문턱을 고정하지 않습니다.

1. `models/profiles/`에 새 ID의 JSON을 추가합니다. 기존 버전 파일은 보존합니다. 같은 규칙 계열이면 `cross_defense_v1` 어댑터의 Cross·방어 설정을 사용합니다.
2. 새로운 코어/규칙이면 `models/`에 어댑터를 추가하고 `models/registry.py`의 `ADAPTERS`에 등록합니다. 반환값은 자산 6종의 목표 DataFrame과 기존 지표 열을 가진 DataFrame입니다.
3. 새 모델의 독립 검증 목표·백테스트 근거를 등록하고 전 기간 일치·미래정보 차단 검사를 추가합니다. `models/evidence/<모델ID>.backtest.json`은 모델 지문과 일치해야 합니다. 검증 없이 과거 성과를 새 모델에 붙이면 `prepare.py`가 차단합니다.
4. `python model.py list`로 모델을 확인하고 `python model.py use woogong-1.3-d`로 선택·미리보기 갱신을 한 번에 실행합니다. 실패하면 이전 설정·자료를 복원합니다. `python -m pytest tests -q`로 검증합니다. 이전 v1으로 되돌리려면 `python model.py use woogong-v1`을 실행합니다. 선택값은 `active_model.json`에 저장됩니다.
5. 서버 코드를 배포하고 계산을 다시 실행하면 같은 날짜여도 모델 지문 변경을 감지해 재계산합니다. 같은 데이터 계약/자산 구성에서는 설치된 앱이 새 결과를 받아 모델명·이유·문턱을 반영하므로 APK를 다시 설치할 필요가 없습니다. 내장 오프라인 예시까지 바꾸려면 APK를 다시 빌드합니다.

`model_id`는 모델 계보, `model_fingerprint`는 설정과 계산 코드, `schema_version`은 앱 데이터 계약을 구분합니다. 목표·상태·모델 명세·백테스트가 서로 다르면 표시/동기화를 제한합니다. 모델 변경은 보유량을 자동 변경하지 않습니다. 자산 구성이 바뀌거나 계약 버전이 올라가면 Android 클라이언트 수정도 필요합니다.

`strategy_parameters.json`과 `models/core_v1.py`는 원본 코어 보존용입니다. 원본 설정의 SHA256 검사를 유지합니다. `tools/import_audit.py`는 이 작업공간의 연구 원본으로 검증 자료를 최초 수입하는 개발 도구이며 실행 시 전 기간 일치를 확인합니다. 일반 실행과 GitHub 운영에는 상위 연구 폴더가 필요하지 않습니다.

## 로컬 실행

Python 3.12 이상에서 다음을 실행합니다.

```powershell
python -m pip install -r requirements.txt
python prepare.py
python -m pytest tests -q
python -m http.server 8768 --bind 127.0.0.1 --directory site
```

브라우저에서 `http://127.0.0.1:8768`을 엽니다. `python pipeline.py --demo`는 선택 모델의 과거 신호만 생성합니다. `python pipeline.py --live`는 추가 키 없이 공개 종가를 조회하며, 원본 가격기준·거래일 연속성·BTC 완료 일봉을 검사합니다. 누락 시 이전 결과를 보존하고 갱신 대기를 표시합니다.

## Android 빌드와 운영

Windows에서는 JDK17·Android SDK36을 준비하고 `JAVA_HOME`·`ANDROID_HOME`을 설정한 뒤 `./build_android.ps1`을 실행합니다. 이 스크립트는 한글 경로 문제를 피하도록 영문 TEMP 경로로 소스만 복사하고, 단위 테스트와 APK 생성을 실행해 `release/`에 결과를 모읍니다. 원본 소스는 이동하지 않습니다. 기존 `.tools/jdk64`·`.tools/sdk`가 있으면 자동 사용합니다. Linux/macOS에서는 `cd android` 후 `./gradlew testDebugUnitTest assembleDebug --no-daemon`을 실행합니다. GitHub에서는 **Android APK** Actions가 선택 모델의 자료 생성·회귀검사 후 APK를 만듭니다. 산출물 이름은 `woogong-debug-apk`입니다.

이 폴더만 별도 GitHub 저장소 루트로 올리고 Pages Source를 GitHub Actions로 설정합니다. `.deps`, `.tools`, 개인 키, 실제 보유량은 올리지 않습니다. 공개 Pages에는 파생 신호와 성과가 공개되므로 가격자료의 외부 배포 권한을 확인해야 합니다.

시세 연결 상태와 공급자별 설정은 [GitHub 연결 안내](GITHUB_SETUP.md)를 확인하세요. 자동 계산은 Yahoo Finance·Bitstamp용이며 메리츠 계좌는 Android에서 직접 조회합니다. 메리츠 키를 GitHub Secrets에 등록하는 절차가 아닙니다. 푸시를 쓰려면 Firebase Android 앱 `com.woogong.app`을 만들고 `GOOGLE_SERVICES_JSON`, `FIREBASE_SERVICE_ACCOUNT_JSON`, `FCM_TOKENS`를 등록합니다. 마지막 값은 앱 설정에서 복사한 기기 토큰의 JSON 배열입니다. 비밀키는 APK 소스에 내장하지 않습니다.

앱 설정에서 Pages의 HTTPS 주소를 저장합니다. 알림 권한을 허용하고 홈 화면에 우공이산 위젯을 추가합니다. **Woogong close calculation** Actions는 미국 휴장·조기폐장·서머타임과 완료된 BTC UTC 일봉을 반영합니다. 계산 결과가 게시되면 휴대폰 백그라운드 조회에서 하루·모델별 한 번 알립니다. 앱 설정의 알림 테스트에서 권한과 채널을 확인할 수 있습니다. Firebase를 추가 설정한 경우 푸시는 조회를 깨우는 선택 경로로 사용합니다. 예약 실행·데이터 제공·폰 절전으로 지연될 수 있습니다.

## 과거 성과의 조건

V1.3-D 동결 검증은 2021-10-20~2026-10-20 실제 BITO·다음 시가·편도0.1%·달러 현금 대용수익·세전 조건입니다. CAGR47.63%, MDD-17.25%입니다. 기본 6조건 최저 CAGR/|MDD|는 달러2.13, 원화1.77이며 실계좌 본운용 승인은 아닙니다.

장기 혼합 대용은 BTC 대용에 연 로그 -10% 드래그를 적용한 별도 연구 조건으로 CAGR72.86%입니다. 상장 전 BITO 실적이 아닙니다. 최신 확장은 다음 종가·현금금리0·분배금 재투자 비용 별도 미반영으로 동결 검증과 조건이 다릅니다. 개인 세금·정수주·실제 호가/체결을 검증한 원장은 아닙니다.
